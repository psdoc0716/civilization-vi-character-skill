# Civilization VI Governor Portrait Skill

Generate stylized Governor portrait prompts from either a historical character name or a descriptive character concept.

## Examples

### Historical character

Input:

岳飞

The skill automatically builds a historically grounded Chinese Song-era military character and translates him into a stylized Governor portrait.

### Descriptive character

Input:

一个中国男性，魁梧、武将、正义

The skill interprets the physical build, cultural context, profession, and personality, then creates a coherent Governor portrait prompt.

## Visual characteristics

- expressive, slightly exaggerated 3D face
- strong character identity
- chest-up / waist-up framing
- polished AAA strategy-game rendering
- PBR materials
- soft studio lighting
- pure white background
- characteristic soft fade at the lower edge
- no text, logo, UI, or scene

## Relationship to the historical character skill

This skill is optimized for Governor-style portraits rather than full-body historical leader portraits.

The historical character skill emphasizes complete body silhouette and costume.

The Governor skill emphasizes facial identity, expression, personality, and compact portrait composition.

## Style reference

The skill uses Civilization VI as a high-level visual reference for strategy-game character presentation. It does not reproduce proprietary character models or assets.
